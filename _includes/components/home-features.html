Features

  • Make .env safe to commit dotenvx encrypt
  • Same on Mac, Linux, and Windows dotenvx run
  • Ship the right secrets to each environment dotenvx run -f .env.production
  • Let agents use secrets without spilling them dotenvx run --redact -- claude
  • Protect your team from secret leaks dotenvx precommit
  • Give .env live, computed values ${OTHER_VAR} $(whoami)
  • Pull secrets remotely from places like 1Password op://.. bw://..
