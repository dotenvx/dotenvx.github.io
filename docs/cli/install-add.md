---

title: install --add
description: Add features while preserving your current Dotenvx version and other
  installed features.
permalink: "/docs/cli/install-add/"
command: dotenvx install --add
eyebrow: dotenvx install
eyebrow_href: "/docs/cli/install/"
---

Pass a feature ID to --add. For example, add Armor:

```console
$ dotenvx install --add armor
```
{: copy="dotenvx install --add armor"}

Repeat --add or pass comma-separated feature IDs to add multiple features.
