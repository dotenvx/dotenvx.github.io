Encrypt

{% include components/design-codeblock.html value=encrypt_example copy_text=encrypt_copy label="Encrypt your .env file" %}

Encrypt your secrets in .env files. The values become ciphertext and only your private key can unlock them.

{% capture commit_example %} $ git add .env $ git commit -m "encrypt .env" {% endcapture %} {% capture commit_copy %} git add .env git commit -m "encrypt .env" {% endcapture %}

Commit

{% include components/design-codeblock.html value=commit_example copy_text=commit_copy label="Commit your encrypted .env file" %}

Commit your encrypted .env files with your code. It's safe. Now you can securely share secrets through git.

{% capture ship_example %} $ dotenvx run -- node index.js ⟐ injected env (2) from .env {% endcapture %}

Ship

{% include components/design-codeblock.html value=ship_example copy_text="dotenvx run -- node index.js" label="Run your deployed app" %}

Ship your code and secrets together. Dotenvx uses your private key to decrypt and inject your secrets just-in-time to your code.
