Remove the Dotenvx pre-commit hook.

```console
$ dotenvx precommit --uninstall
```
{: copy="dotenvx precommit --uninstall"}

The hook is removed only when it matches the hook managed by Dotenvx. --uninstall cannot be combined with --install.
