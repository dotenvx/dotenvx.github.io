---
title: Install Dotenvx on Windows
description: Install the Dotenvx CLI with WinGet and verify the installation.
permalink: /docs/install/windows/
---

In PowerShell, install the Dotenvx CLI with WinGet.

```powershell
winget install dotenvx
```

Verify the installation by printing the installed version.

```powershell
dotenvx --version
```
