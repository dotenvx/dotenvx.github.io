# `/v2` design rules

- Every v2 page exports its content as raw Markdown at the matching `.md` URL (for example `/v2/about.md`), with `/v2/index.md` for Home. Exports include no navigation or footer and are generated from the same content as the web page.

- Only use `h1`, `h2`, and `h3`. If the content needs `h4`, `h5`, or `h6`, simplify its structure.
- Use the paragraph font size for `h3` and set it in bold.
- Style quotes like the newsletter: native `blockquote`, normal 14px text with 24px line spacing, a 2px gray left rule, 16px left inset, and 20px bottom spacing. Preserve `>` markers in Markdown exports.
- Use native `ul`, `ol`, and `li` elements matching the newsletter: 20px left list padding, outside markers, 24px line height, 12px gaps for bullets, and 20px gaps for numbered items. Wrapped lines align with item text. Do not use custom markers, counters, or table cells for list alignment; marker placement may vary slightly by email client.
- Set `writer_layout` in a source page's front matter to `auto` (the default), `single`, `columns`, or `wide`. Auto uses a centered 440px column for fewer than 250 rendered words and newspaper columns for longer content. Pricing explicitly uses `wide` for its comparison table.
- For pages using columns, keep one column on smaller screens, two from 1000px, and three from 1480px. Cap multi-column text at 380px per column, with space for hanging heading markers.
- Column pages progressively adjust native column height so the final column fits the visible area below the title when possible. Earlier columns can run longer. Keep paragraphs, headings with following content, and code blocks together. Recalculate for resizing, fonts, and images; retain normal balanced columns if an indivisible final block cannot fit. Single-column pages, pricing, mobile, and raw Markdown keep their normal flow.
- Let the footer span the page with the same side gutters as the top nav. Use equal columns for contact information and links, and stack them on small screens. Use underlined links with spacing between them, wrapping whole link labels onto the next line.
- Omit decorative trailing arrows from link labels.
- Set code blocks in regular monospace with 24px line spacing and a thin, padded border. Mute shell prompts and use amber for successful output.
- Place the Copy icon in the top-right corner of web code blocks.
