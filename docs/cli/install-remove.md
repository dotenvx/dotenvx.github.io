---
doc_type: cli
title: install --remove
description: Remove features while preserving your current Dotenvx version and other
  installed features.
permalink: "/docs/cli/install-remove/"
command: dotenvx install --remove
eyebrow: dotenvx install
eyebrow_href: "/docs/cli/install/"
---

Pass a feature ID to --remove. For example, remove Armor:

```console
$ dotenvx install --remove armor
```
{: copy="dotenvx install --remove armor"}

Repeat --remove or pass comma-separated feature IDs to remove multiple features.
